نواتج التعلم (نافس)
ملف واحد _worker.js يخدم الواجهة والـ API معًا على Cloudflare Pages، مع قاعدة بيانات D1.
الجداول تُنشأ تلقائيًا عند أول تشغيل، فلا حاجة لتشغيل أي SQL يدويًا.
خطوات النشر
	1.	GitHub: أنشئ مستودعًا جديدًا وارفع ملف _worker.js في جذر المستودع، ويمكن رفع هذا الملف معه.
	2.	قاعدة البيانات: من لوحة Cloudflare افتح Workers & Pages ثم D1 ثم Create database، وسمّها مثلًا bna-db.
	3.	مشروع Pages: من Workers & Pages اختر Create ثم Pages ثم Connect to Git، واختر المستودع.
	•	Framework preset: None
	•	Build command: اتركه فارغًا
	•	Build output directory: /
	4.	ربط القاعدة: من إعدادات المشروع افتح Settings ثم Bindings ثم Add ثم D1 database.
	•	Variable name: DB (بأحرف كبيرة تمامًا)
	•	D1 database: bna-db
	5.	إعادة النشر: من Deployments اضغط Retry deployment على آخر نشر حتى يعمل الربط.
	6.	افتح رابط المنصة، ثم اختر تبويب مشرف وأنشئ حساب المشرف الرئيسي. هذه الشاشة تظهر مرة واحدة فقط.
بعد الدخول كمشرف
	1.	من الإعدادات: اكتب اسم المدرسة، وحدد تاريخ بداية الأسبوع الأول. أيام الاختبار الافتراضية هي الأحد والاثنين.
	2.	من الطلاب: حمّل النموذج، املأه، ثم استورده. يمكنك اختيار الإضافة والتحديث، أو المزامنة الكاملة.
	3.	من المعلمون: أضف كل معلم وأسند له مواده.
	4.	المواد الافتراضية لكل الصفوف: لغتي، الرياضيات، العلوم، اللغة الإنجليزية. يمكن تعديلها من المواد عند الحاجة.
	5.	من بنك الأسئلة: يضيف المعلم أسئلة كل أسبوع يدويًا أو من إكسل.
التحديث لاحقًا
استبدل _worker.js في GitHub بالنسخة الجديدة، وسينشر Cloudflare تلقائيًا. البيانات في D1 لا تتأثر.
قياس الأثر
تبويب «قياس الأثر» متاح للمشرف ولكل معلم في مواده. اختر الصف، ثم مادة واحدة أو «جميع المواد»، ويمكن التصفية بالفصل.
	•	تقرير أسبوعي PDF لكل أسبوع فيه نتائج: المشاركة، والمتوسط، والإتقان، والتغير عن الأسبوع السابق، ونتيجة كل طالب مقارنة بنتيجته السابقة.
	•	تقرير تراكمي PDF لخمسة عشر أسبوعًا: منحنى الأثر، ونسبة التغير بين بداية الفترة ونهايتها، ورسم لتغير كل طالب، وخريطة نتائج الطلاب أسبوعًا بأسبوع.
	•	عدد أسابيع القياس (15 افتراضيًا) يُعدَّل من الإعدادات.
	•	لحفظ التقرير كملف: اضغط «حفظ PDF»، ثم اختر «حفظ بتنسيق PDF» من نافذة الطباعة. على الجوال: مشاركة، ثم طباعة، ثم حفظ في الملفات.
